# ANA-D Agent Implementation Guide

This guide outlines the implementation of the **ANA-D (Analog Designer)** agent using the `openhands-software-agent-sdk`. ANA-D acts as an orchestrator that delegates circuit design tasks to **ANA-W1 (Analog Worker)** and manages the iterative refinement process with human feedback.

## Core Responsibilities

1.  **Orchestration (Iteration 1):** Delegate to `ANA-W1` with a `circuit generation` prompt.
2.  **Review and Correction (Iteration 2+):**
    *   Analyze generated artifacts.
    *   Prepare a findings document.
    *   Prompt the human for feedback.
    *   Delegate to `ANA-W1` with a `circuit correction` prompt based on findings and human input.
3.  **Termination:** Loop until the human accepts the design.

## Implementation Steps

### 1. Setup and Registration
Register `ANA-W1` as a sub-agent. You can leverage the existing configuration from `ana_worker_1.py`.

```python
from openhands.sdk import Agent, LLM, Conversation, Tool, AgentContext
from openhands.tools.delegate import DelegateTool, register_agent, DelegationVisualizer
from openhands.tools.preset.default import get_default_tools

# 1. Define ANA-W1 factory
def create_ana_w1(llm: LLM) -> Agent:
    # Use the same system prompt and tools as in ana_worker_1.py
    system_prompt_path = "ana_worker/ana_w1_system_prompt.j2"
    tools = get_default_tools() # or specific tools like TerminalTool, FileEditorTool
    
    return Agent(
        llm=llm,
        tools=tools,
        system_prompt_filename=system_prompt_path,
        # Add skills if necessary, as seen in ana_worker_1.py
    )

# 2. Register ANA-W1
register_agent(
    name="ana_w1",
    factory_func=create_ana_w1,
    description="Expert in analog circuit generation and correction."
)

# 3. Setup ANA-D (Main Agent)
tools = [Tool(name="DelegateTool")]
ana_d_agent = Agent(llm=llm, tools=tools)
conversation = Conversation(
    agent=ana_d_agent,
    workspace=cwd,
    visualizer=DelegationVisualizer(name="ANA-D")
)
```

### 2. Iteration 1: Transparent Delegation
ANA-D delegates the initial construction to ANA-W1 without adding new information.

```python
# The 'circuit generation' prompt as requested
circuit_gen_prompt = "Please generate the initial analog circuit based on the provided SCUD and schematics."

initial_task = (
    f"Delegate to ana_w1 with the following prompt: '{circuit_gen_prompt}'. "
    "Do not add any new information or update core artifacts yourself. Just orchestrate."
)
conversation.send_message(initial_task)
conversation.run()
```

### 3. Iteration 2+: Review and Refinement Loop
After the first run, ANA-D checks artifacts, prepares findings, and prompts the human.

```python
while True:
    # 1. ANA-D analyzes artifacts
    conversation.send_message(
        "Check the generated circuit artifacts in the workspace for accuracy. "
        "Create a document 'findings.md' suggesting updates in the circuit."
    )
    conversation.run()
    
    # 2. Extract findings (ANA-D will have written this to findings.md)
    with open("findings.md", "r") as f:
        findings = f.read()
    
    # 3. Prompt Human for input
    print(f"\n--- ANA-D Review Findings ---\n{findings}")
    human_feedback = input("\nEnter feedback (or type 'proceed' to accept): ")
    
    if human_feedback.lower() == "proceed":
        print("Design accepted. Finalizing...")
        break
    
    # 4. Trigger correction with ANA-W1
    # The 'circuit correction' prompt as requested
    circuit_corr_prompt = (
        f"Correct the circuit based on these findings: {findings}\n"
        f"And this human feedback: {human_feedback}"
    )
    
    correction_task = (
        f"Delegate to ana_w1 with the 'circuit correction' prompt: '{circuit_corr_prompt}'."
    )
    conversation.send_message(correction_task)
    conversation.run()
```

## Key Considerations

*   **Transparency:** In the first iteration, ensure ANA-D's system prompt or the initial message strictly instructs it to delegate without modification.
*   **Artifact Access:** ANA-D must have tools (like `FileEditorTool` or `TerminalTool`) to read the files generated by ANA-W1 if it needs to analyze them directly.
*   **State Management:** The `Conversation` object maintains the history, allowing ANA-D to remember previous iterations and feedback.
*   **Delegation Tooling:** Ensure `DelegateTool` is correctly added to ANA-D's toolset.
