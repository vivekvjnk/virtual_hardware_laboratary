
# Virtual Hardware Lab: ANalog circuit design Agent(ANA)

## Vertex AI setup

Create Google cloud account, enable billing account
Create project and link billing account
Enable vertex ai in project
Create and download JSON credentials by following the steps.

Steps to Download JSON Credentials
Navigate to Service Accounts: Open the Google Cloud Console and go to IAM & Admin > Service Accounts.
Select Your Project: Ensure the correct project ID is selected in the top-bar dropdown.
Choose a Service Account: Click on the email address of the service account you want to use for Vertex AI.
Create a New Key:
Click the Keys tab.
Click the Add Key dropdown and select Create new key.
Download the File:
Select JSON as the key type.
Click Create. The JSON file will automatically download to your computer.
